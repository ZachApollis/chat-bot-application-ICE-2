# chat-bot-application-ICE-2
Project Description

This project is a Java-based Text-to-Speech and Chatbot application developed as part of an Information and Communication Technology Extension ICE task.

The application uses the FreeTTS library to convert text into speech and provides a simple chatbot that responds to basic user inputs.

For this ICE task, the existing application was expanded by adding a Voice Modulation feature. This allows the user to change the speech rate, pitch, and volume of the voice used by the Text-to-Speech system.

Main Features:

 Text-to-Speech conversion
 Chatbot with predefined responses
 List of available voices
 Voice modulation
 Adjustable speech rate
 Adjustable pitch
 Adjustable volume
 Console-based menu system
 Input error handling



How to Run the Application:

Requirements

To run this application, you will need:

 Java Development Kit (JDK)
 NetBeans IDE
 FreeTTS libraries

Steps:

1. Download or clone this repository.
2. Open NetBeans.
3. Select File → Open Project.
4. Select the downloaded project folder.
5. Make sure the FreeTTS libraries are correctly added to the project.
6. Run the ProgICE1 class.
7. Use the menu displayed in the console to select a feature.



Usage Guide:

When the application starts, the following menu is displayed:

1. Text to Speech
2. Chatbot
3. All available voices
4. Voice Modulation
5. Exit

1. Text to Speech

Select option 1 and enter text.

The application will use the selected FreeTTS voice to read the text aloud.

2. Chatbot

Select option 2 to start the chatbot.

The chatbot can respond to predefined inputs such as greetings and goodbye messages.

Type exit to end the chatbot.

3. All Available Voices

Select option 3 to display the voices available through the FreeTTS system.

4. Voice Modulation

Select option 4 to change the voice settings.

The user can enter values for:

 Speech rate
 Pitch
 Volume

These settings are then applied when the Text-to-Speech feature is used.

5. Exit

Select option 5 to close the application.
